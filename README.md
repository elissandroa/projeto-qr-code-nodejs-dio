# 🚀Projeto QR-Code NodeJS DIO

Gere QR Codes de forma simples, rápida e eficiente com Node.js!  
Este projeto faz parte do bootcamp da Digital Innovation One (DIO), demonstrando habilidades em JavaScript, Node.js e integração com bibliotecas modernas.

## ✨ Sobre o Projeto

O **projeto-qr-code-nodejs-dio** foi desenvolvido para facilitar a criação de QR Codes personalizados a partir de qualquer texto ou link, com uma interface simples e código limpo. Ideal para empresas, eventos, marketing ou uso pessoal!

- **Tecnologias:** Node.js, JavaScript, bibliotecas modernas de geração de QR Code
- **Destaque:** Código modular, fácil manutenção e foco em boas práticas

## 💡 Funcionalidades

- Gerar QR Codes a partir de textos ou URLs
- Opção de salvar QR Codes como imagem
- Interface de linha de comando intuitiva
- Fácil integração com outras soluções Node.js

## 🛠️ Tecnologias Utilizadas

- [Node.js](https://nodejs.org/)
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)
- [qrcode](https://www.npmjs.com/package/qrcode) (biblioteca para geração de QR Codes)
- [fs](https://nodejs.org/api/fs.html) (para manipulação de arquivos locais)

## 🚩 Como Executar

```bash
# Clone o repositório
git clone https://github.com/elissandroa/projeto-qr-code-nodejs-dio.git

# Acesse a pasta do projeto
cd projeto-qr-code-nodejs-dio

# Instale as dependências
npm install

# Execute o projeto
node index.js
```

Siga as instruções no terminal para gerar seu QR Code personalizado!
